# Wisch weg! 💩

Der Bildschirm wird von innen braun – wisch den Dreck mit dem Finger weg, bevor alles zu ist. Rekord wird gespeichert.

- `game/index.html` – das Spiel (reines HTML/Canvas, auch im Browser spielbar)
- `android/` – WebView-Hülle → APK (`gradle assembleDebug`, braucht Android SDK 34)
- `wisch-weg.apk` – fertig gebaute Debug-APK zum direkten Installieren (unbekannte Quellen erlauben)
